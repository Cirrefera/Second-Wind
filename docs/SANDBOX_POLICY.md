# Product preview eligibility

The approved allowlist in `workers/gateway/src/sandbox-policy.js` is the authority for which products may offer trials. It contains 72 of the 157 catalog identities. The remaining 85 are excluded, including the retired proof item. Product type alone never grants eligibility: some artifact and tool listings are excluded too.

| Policy | Public metadata | New trial behavior |
| --- | --- | --- |
| Excluded | `sandbox_eligible: false`, `sandbox_available: false`; no trial/access URL | Rejected before sandbox acceptance or charge |
| Eligible, runtime/release unavailable | `sandbox_eligible: true`, `sandbox_available: false`; no trial/access URL | Rejected before sandbox acceptance or charge |
| Eligible, published compatible preview | Both flags `true`; trial/access URLs present | Separate $0.01 official x402 admission; product purchase remains optional |

Source preparation, a drafted preview, proportional pricing, or an authored package does not activate a trial. HTTP and Cap’n Web share the same trial-access policy. Recovery retrieves the original saved result and does not execute or charge again.
